# Jogo de Tarot - 4 Cartas

Projeto de um jogo interativo de Tarot, onde o usuário pode "tirar" quatro cartas aleatórias e revelar seus significados.

---

## Funcionalidades

- Sortear 4 cartas aleatórias do baralho de Tarot.

---

## Tecnologias usadas

- HTML5
- CSS3 
- JavaScript (ES6+)
- JSON para dados das cartas
- Áudio em formato MP3

---

## Como usar

1. Clone ou faça download do repositório ou acesse por esse link: https://vihari2.github.io/TAROT-o-jogo/
